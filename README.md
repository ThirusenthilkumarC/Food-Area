## 🍽️ About The Project

**Food Area** is a premium restaurant website created to provide a visually appealing and user-friendly food ordering experience.

The project focuses on:

* 🎨 Modern & premium UI design
* 📱 Fully responsive layouts
* ⚡ Fast performance with Vite
* ✨ Smooth animations and interactions
* 🛒 Online food ordering experience
* 🧩 Reusable React components

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/ThirusenthilkumarC/Food-Area.git
```

### 2️⃣ Navigate to the Project

```bash
cd Food-Area
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start Development Server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.

---

## 🧑‍💻 Development

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
